# SEO, LLM discovery, and GA4 coverage — 2026-10-05

## What changed

- Every recognized site route now carries GA4's built-in `content_group` parameter on its explicit page view. Groups distinguish personality pages, play and results routes, trivia, driving, weekly news, daily minis, social pages, live events, site pages, and the 404 route. The group is derived only from the canonical pathname after the existing allowlist check.
- Result, room, query-string, hash, answer, score, reflection, nickname, and browser-storage data remain outside the analytics contract. The existing manual SPA page-view implementation continues to use `send_page_view: false`; GA4 Enhanced Measurement history page views must remain disabled in the property to prevent duplicates.
- The public Organization schema now names the verified TypologyQuiz TikTok profile. Existing canonical URLs, Open Graph metadata, Twitter cards, `Quiz`/breadcrumb JSON-LD, sitemap checks, and the generated `llms.txt` remain the discovery foundation.

## LLM discovery approach

Google's current guidance is to prioritize crawlable, useful, original pages and ordinary technical SEO rather than special AI files or synthetic mentions. `llms.txt` stays as a truthful directory for systems that choose to read it; it is not treated as a ranking mechanism. New structured data must match immediately visible content, and no answer keys, ratings, reviews, or invented interaction counts are added.

## Validation required for release

1. Regenerate and check the analytics manifest; it is the route allowlist and fails closed for unknown paths.
2. Run analytics tests and the production build/discovery checks.
3. Build with the approved production GA variables, then inspect a clean-browser request and GA4 DebugView/Realtime. Confirm one explicit page view per canonical transition and no query, hash, results, answer, nickname, or reflection marker in the request.
4. Keep Search Console and GA4 reporting separate: structured data, sitemap inclusion, and `llms.txt` do not guarantee indexing, a rich result, or AI citation.
