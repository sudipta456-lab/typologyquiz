# Review of the 250-quiz plan

October 18, 2026. Scope: concept briefs and delivery plan, not production question banks or a new code audit.

## Review performed

The lead review covered all ten category drafts and checked example tasks, distinct premises, source relevance and implementation dependencies. A separate Claude Opus review assessed the supplied briefs. Its first attempt exceeded the output limit; a bounded second pass completed and returned ten grouped findings. The findings were adjudicated and the catalog was revised. The reviewer had no repository or web tools; its source interpretations were checked against the actual retrieved evidence rather than accepted automatically.

## Changes made

- Repaired underdetermined logic examples: unique seating and house orders, a uniquely removable false rule, a closed simultaneous gift exchange, explicit shortest-path rules and defined vowel/length gates.
- Corrected examples involving mixing versus mastering, interpolation versus covers, ambiguous screen-role release decades, cranked historical objects, device sounds and controller release dates.
- Replaced subjective answer keys with explicit briefs, definitions, declared requirements or unscored preferences. The first movie pilot now tests identifiable film techniques rather than inferred emotional effects.
- Added a separate many-to-many **graph** dependency, including accepted edge sets and false-positive handling. Retained **layers** for simpler repeated-target relations. Added **sequence** wherever several valid orders must be accepted.
- Made additional preference scoring explicit for visual, audio, branching and relation-based preference quizzes. Hybrid results keep accuracy and preference separate.
- Corrected shared-device social-state requirements and clarified where a group supplies just one shared response.
- Replaced repeated concepts with **Flat Map, Round World**, **Predict, Reveal, Revise**, **What Survives the Reload?**, **Postcard Perspective Puzzle**, **Same Distance, Different Numbers**, **Spot the Unspoken Assumption**, and **Seven Guests, Four Servings**.
- Replaced generic repeated result axes with task-specific dimensions. Future item writing must support those dimensions; changing labels alone is insufficient.
- Downgraded several tangential trend tags to evergreen. The reviewer incorrectly said Google Canada's source lacked whimsy and liminal-space findings; the retrieved October 14 article contains both, so that contextual link remains. Pinterest's May report also explicitly includes watch-party food, so that narrow context remains. Neither is described as quiz-performance evidence.
- Promoted **MT-03 Film Craft Decoder** and **GT-02 City-Region-Country Relay** to their categories' Wave A positions; IDs are stable identifiers, not priority numbers.

Using the same control in different categories is intentional. We retained cases where the knowledge, constraints and result are substantively different—for example, interpreting sound-design briefs and recognizing clearly demonstrated kitchen actions. Reusing a renderer alone does not make two quizzes duplicates; a cosmetic topic swap without a new decision or learning objective does.

## Remaining production work

Each brief still needs a complete authored bank, answer-level sources, rights checks where relevant, scoring specifications and real playtesting. The catalog's example tasks are not a released quiz. Structural validation does not certify factual correctness, cultural suitability or engagement. Existing quizzes and application code were not changed by this planning work.
