# Music: 25 new quizzes

[Catalog index](README.md) · [Delivery plan](../QUIZ_EXPANSION_250_PLAN_2026-10-18.md) · [Evidence ledger](SOURCES.md)

Proposed concepts, October 18, 2026. All require newly authored question banks and separate slugs. Seeds illustrate tasks; they are not fact-checked answer keys. Wave A = category pilot; B = next four; C = next ten; D = final ten. Dependencies override wave priority. Most target 3–6 minutes; actual durations require playtesting. Research references support rationale, not factual answers.

## MU-01 · Build the Opening Three Songs

**Wave A · Type: preference · experimental · Build: preference**

Design the first three moments of a set using mood cards instead of song titles, then see your opening style.

**Rounds:** 3 openers: order described moods into a set → 4 pairs: choose the stronger first-song promise.

**Example task:** Your room is half-full and nervous. Which opener fits: a slow-building groove, a loud shared chorus, or a quiet spotlight moment?

**Result:** Opening-set card: Slow Build vs Immediate Hook and Smooth Transitions vs Sharp Contrasts.

**Audience:** Casual listeners, playlist makers, hobby DJs. **Proposed slug:** `build-opening-three-songs`.

**Evidence:** [X00](SOURCES.md).

**Production:** Write mood cards with no real song titles or lyrics. Review for genre-neutral wording; no scientific claims about forced choice. Requires new preference scoring; never use correct/incorrect credit for taste choices. Author balanced items specifically for these named dimensions; do not reuse generic Plan/Improvise or Solo/Shared vectors.
